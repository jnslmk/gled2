# SVG

We decided to use SVG files for describing a lamp and an installation, as there are really good open source editors like [inkscape](https://inkscape.org/) and the main workflow of GLED should be animations, not setting up an installation.

In this section you will learn
* [What a group is](groups.md)
* [How to create a svg file for a lamp](lamp.md)
* [How to set up an installation](installation.md)
